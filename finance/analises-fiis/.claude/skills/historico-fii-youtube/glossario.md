# Glossário de correções da transcrição automática

Como a legenda automática escreve → forma correta. Entradas marcadas com (confirmado) foram confirmadas pelo usuário. Acrescente aqui toda correção que o usuário confirmar.

## Tickers e fundos
- "Fatine11", "Fatine 11", "fatien" → FATN11 (confirmado)
- "JCR11", "JR11", "JSR11", "JSR 111", "JCRE11", "JTC R11", "JCN" → JSRE11
- "TP11", "TEP 11", "Tep 11" → TEPP11
- "PVB1", "PVB 11", "pvb 11", "PVB em 11" → PVBI11
- "dgpo 111", "hgp 111" → HGPO11
- "JSAF", "JSAF11", "J saf 11" → JSAF11 (FoF do Safra)
- "SAR 11", "Sani11", "S 11" → SARE11 (fundo do Santander)
- "KNR11" → KNRI11 (Kinea)
- "rbrp11" → RBRP11
- "Vex" (fundo residencial) → Vectis, VCRR11 (confirmado)

## Lugares e imóveis
- "Chukidan", "Chuk Zaidan", "Chusa Zaidan", "shidan", "Zaidan" → Chucri Zaidan
- "Berrine", "berina" → Berrini
- "Rocha Verá", "Rocha Vera" → Rochaverá
- "Tower brid", "tower tower bid" → Tower Bridge
- "WTNU", "Torre Nações Unidas" → WTorre Nações Unidas (confirmado)
- "Sequoia Bela Cintra" → Work Bela Cintra (ex-SARE11) (confirmado)
- "W tem Morumbi" → WT Morumbi

## Termos
- "setipado", "CT pago", "fundo cipado" → fundo cetipado (não listado em bolsa, registrado na Cetip/B3 balcão)
- "corta subordinada", "cote subordinada" → cota subordinada
- "RMG" → renda mínima garantida
- "capwight" → cap rate
- "turn" (modelo) → turn key
- "Celesf", "CL feito", "clube FI", "Clube FIIA" → Clube FII (site), salvo contexto claro em contrário
