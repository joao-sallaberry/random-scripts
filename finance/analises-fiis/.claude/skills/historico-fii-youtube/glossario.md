# Glossário de correções da transcrição automática

Como a legenda automática escreve → forma correta. Entradas marcadas com (confirmado) foram confirmadas pelo usuário. Acrescente aqui toda correção que o usuário confirmar.

- "Fatine11", "Fatine 11", "fatien" → FATN11 (confirmado)
- "JCR11", "JR11", "JSR11", "JSR 111", "JCRE11", "JTC R11", "JCN" → JSRE11
- "TP11", "TEP 11", "Tep 11" → TEPP11
- "PVB1", "PVB 11", "pvb 11", "PVB em 11" → PVBI11
- "dgpo 111", "hgp 111" → HGPO11
- "JSAF", "JSAF11", "J saf 11" → JSAF11 (FoF do Safra)
- "SAR 11", "Sani11", "S 11" → SARE11 (fundo do Santander)
- "KNR11" → KNRI11 (Kinea)
- "rbrp11" → RBRP11
- "prsv", "prcv" → PRSV11 (confirmado; o autor do Liberdade é Logo Ali o chamou de "Rio Bravo Renda Corporativa", provavelmente por engano)
- "jscr", "JSCSR" (fundo de CRI do Safra) → JSCR11 (confirmado)
- "edga", "Edgar", "edig" → EDGA11
- "JSRR", "JSRA", "JRI", "JCRI", "JSRI" → JSRI11 (JS Renda Imobiliária, fundo master do Safra)
- "Core 11" → KORE11
- "hgre" → HGRE11
- "BRCE" → BRCR11
- "Vex" (fundo residencial) → Vectis, VCRR11 (confirmado)
